Manter um README atualizado sempre foi uma dor. Você configura actions crons para atualizar estatísticas todo dia às 2am, tem conflito de merge silencioso no seu próprio perfil, e o visual é sempre aquele bloco de markdown sem graça.

Eu estava cansado dessa limitação, especialmente porque meu portfólio deveria refletir meu cuidado com design de produto.

Foi assim que nasceu o [SeuProduto]...
(O artigo segue contrastando a dor das ferramentas padrão com a facilidade do drag-and-drop do novo produto).
